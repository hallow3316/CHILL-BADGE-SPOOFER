## About

**CHILL × BADGE** is a lightweight Discord badge customization extension by **HALLOW**, designed to give users more control over how their Discord profile badges appear.

A simple experience with a clean interface and easy customization.

**Your profile. Your style.**

---

## Features

- HyperSquad badge customization
- Game Variety badge spoofer
- Game Time badge spoofer
- Simple and lightweight
- Clean dark interface
- Easy-to-use customization
- CHILL × BADGE interface
